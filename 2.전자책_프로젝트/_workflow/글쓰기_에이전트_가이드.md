# 글쓰기 에이전트 (Chapter Writer Agent)

## 개요
각 인터뷰이의 요약/인사이트/에피소드를 하나의 유기적인 챕터로 작성하는 에이전트

## 워크플로우

```
[사용자 입력: 인터뷰이 선택]
    ↓
[AI 질문 세션: 5가지 선택형 질문]
    ↓
[사용자 응답 수집]
    ↓
[AI 초안 생성]
    ↓
[저장: 2.전자책_프로젝트\2.3_전자책 초안\[인터뷰이].md]
```

## ⚙️ AskUserQuestion 5단계 대화형 프로세스

**사용자 선택값:**
- 작성 관점: AI 입문자 관점
- 타겟 독자: E-book 전용 새로운 페르소나
- 글자 수: 1,500자 / 2,000자 / 3,000자
- 문체: 짧고 간결

---

### 1️⃣ **인터뷰이 선택** (header: "인터뷰이")
```
질문: "어떤 인터뷰이의 챕터를 작성하시겠어요?"
타입: 단일선택
```
- 2.1_원본/ 폴더의 인터뷰 파일들을 동적으로 로드
- 예시:
  - 도시가스 안전기획자
  - 화상영어교사
  - 공공기관 사무직
  - (추가 인터뷰이들...)

---

### 2️⃣ **작성 이유 & 목표** (header: "작성 관점")
```
질문: "이 챕터를 어떤 목표로 작성할까요?"
타입: 단일선택
선택지:
```
- **① 기초 개념 설명**
  - AI가 뭐죠? 왜 배워야 해요? (입문자 눈높이)
  - 접근성: 아주 높음

- **② 실전 사례 중심**
  - 실제 적용 사례와 배운 점 강조
  - 접근성: 중간

- **③ 통찰력 & 교훈**
  - 인터뷰이가 얻은 핵심 인사이트
  - 접근성: 중간~높음

- **④ 커리어 관점**
  - 이 이야기가 직무 능력에 어떻게 도움?
  - 접근성: 중간

---

### 3️⃣ **타겟 독자층 명확화** (header: "타겟 독자")
```
질문: "이 e-book을 읽을 주요 대상은?"
타입: 복수선택 가능
선택지:
```
**E-book 전용 새로운 페르소나:**

- **① AI 입문 준비생**
  - AI 개념을 처음 배우는 사람
  - 기술 배경 없음, 호기심 있음

- **② 직무 전환 희망자**
  - AI 시대에 경력을 준비 중인 사람
  - 실무 경험 있으나 AI는 낯선 분야

- **③ 비기술직 종사자**
  - 개발이 아닌 기획/마케팅/운영진
  - 조직에서 AI 이해도 필요

- **④ 학생 (대학생/취준생)**
  - 미래 커리어 준비 중
  - 동료 학습자와의 공감 원함

---

### 4️⃣ **글자 수 선택** (header: "분량")
```
질문: "목표 글자 수는 어느 정도가 좋을까요?"
타입: 단일선택
```
- **① 1,500자**
  - 간단한 소개 / 핵심만 담기
  - 독서시간: 5~7분
  - 용도: 빠른 인사이트 필요할 때

- **② 2,000자**
  - 표준 길이 / 균형잡힌 설명
  - 독서시간: 8~10분
  - 용도: 가장 일반적인 챕터

- **③ 3,000자**
  - 상세 설명 / 심화 내용 포함
  - 독서시간: 12~15분
  - 용도: 깊이있는 학습 원할 때

---

### 5️⃣ **문체 & 추가 요소** (header: "스타일")
```
질문: "추가 요소를 포함할까요?"
타입: 복수선택
```

**기본 문체: 짧고 간결**
- 한 문장 = 30~50자
- 단락 = 3~5문장
- 구어체, 친절한 톤
- AI 입문자 눈높이

**선택 가능 요소:**

- **① 핵심 정리 박스** ✅
  ```
  > 🎯 이 챕터의 핵심
  > - 포인트1
  > - 포인트2
  ```

- **② 실전 팁 (💡 마크)**
  ```
  💡 실전 팁:
  - 당신도 이렇게 시작할 수 있습니다
  ```

- **③ 용어 설명 (📚 마크)**
  ```
  📚 용어 설명:
  - 머신러닝: 컴퓨터가 스스로 학습하는 방식
  ```

- **④ 더 읽을거리**
  ```
  📖 더 읽을거리:
  - 관련 주제 추천 링크
  ```

- **⑤ 특별히 없음**
  - 자연스러운 흐름만 유지

## 문체 가이드

**기본 원칙**:
- 존댓글 사용 (존중의 기본)
- 단어 선택 일관성
- AI 초보자도 이해하기 쉬운 설명
- 다정하고 따뜻한 톤

**예시 문체**:
```
이 이야기를 통해 우리가 발견하는 것은,
기술이 우리의 삶을 단순히 '편하게' 만드는 것만이 아니라
우리가 누구인지를 묻게 만든다는 점입니다.
```
