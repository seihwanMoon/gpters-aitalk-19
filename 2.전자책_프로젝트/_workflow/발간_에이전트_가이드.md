# 발간 에이전트 (Publishing Agent)

## 📚 에이전트 개요

완성된 챕터들을 순서에 맞게 통합하여 전문가 수준의 PDF e-book을 생성하는 에이전트입니다.

**핵심 목표:**
- 여러 챕터를 자동으로 통합
- PDF 레이아웃 및 표지 적용
- 자동 목차 생성 및 사용자 검증
- 완성된 e-book 발간

---

## 🔄 워크플로우

```
[Step 1: 챕터 파일 선택]
    ↓
[Step 2: PDF 레이아웃 템플릿 선택]
    ↓
[Step 3: 표지 디자인 입력]
    ↓
[Step 4: 목차 자동 생성 + 사용자 검증]
    ↓
[Step 5: 최종 확인 & PDF 생성]
    ↓
[저장: 2.4_전자책_발간\ 폴더]
```

---

## ⚙️ AskUserQuestion 5단계 대화형 프로세스

**사용자 선택값:**
- PDF 레이아웃: 기본 / 심플 / 고급
- 표지 디자인: 사용자 입력형
- 목차 생성: 사용자 검증 후 생성
- PDF 출력: 2.4_전자책_발간/

---

### Step 1: 챕터 파일 선택
```
질문: "발간할 챕터들을 선택해주세요"
타입: 복수선택 (순서 중요)
```
- 2.3_전자책 초안/ 폴더의 .md 파일 동적 로드
- 선택 순서가 e-book의 챕터 순서 결정
- 예시:
  ```
  ☑ 도시가스_안전기획자_챕터_2024-11-01.md
  ☑ 화상영어교사_챕터_2024-11-02.md
  ☑ 공공기관_사무직_챕터_2024-11-03.md
  ```

---

### Step 2: PDF 레이아웃 템플릿 선택
```
질문: "어떤 PDF 레이아웃을 적용할까요?"
타입: 단일선택
```

- **① 기본 (Basic)**
  - 기본 폰트: 나눔고딕
  - 마진: 1인치
  - 색상: 검은색 텍스트 + 회색 구분선
  - 특징: 심플하고 깔끔
  - 용도: 표준 e-book

- **② 심플 (Simple)**
  - 기본 폰트: 나눔명조
  - 마진: 0.8인치
  - 색상: 진회색 텍스트 + 파란 강조
  - 특징: 미니멀하고 모던
  - 용도: 현대적 느낌 원할 때

- **③ 고급 (Premium)**
  - 기본 폰트: 나눔고딕 + 나눔명조 혼합
  - 마진: 1.2인치
  - 색상: 다크 테마 + 강조 컬러
  - 특징: 고급스럽고 전문적
  - 용도: 프리미엄 e-book

---

### Step 3: 표지 디자인 입력
```
질문: "e-book 표지 정보를 입력해주세요"
타입: 사용자 입력형 (4가지 필드)
```

**입력 필드:**

1. **📘 책 제목** (필수)
   - 예: "AI 시대의 커리어 변화"
   - 최대: 30자

2. **👤 저자명** (필수)
   - 예: "도시가스 안전기획자, 화상영어교사 외"
   - 최대: 50자

3. **📝 부제목** (선택)
   - 예: "전직자들이 말하는 AI와의 공존"
   - 최대: 50자

4. **🎨 표지 이미지** (선택)
   - 선택지:
     - 사용자 업로드 (./Attach/ 폴더 이미지)
     - 기본 제공 이미지 사용
     - 텍스트만 사용 (이미지 없음)

---

### Step 4: 목차 자동 생성 & 사용자 검증
```
질문: "생성된 목차를 확인해주세요"
타입: 검증 후 수정 가능
```

**자동 생성 프로세스:**
- Step 1에서 선택한 파일들의 제목 추출
- 자동 순번 매김 (Chapter 1, 2, 3, ...)
- 페이지 번호 예상 할당

**예시 목차:**
```
🔖 목차

  Chapter 1. 도시가스 안전기획자의 AI 경험
              .................................... 1

  Chapter 2. 화상영어교사가 본 AI의 미래
              .................................... 15

  Chapter 3. 공공기관 사무직의 디지털 전환
              .................................... 28

  부록: 인터뷰이 소개
              .................................... 42
```

**사용자 선택:**
- ☑ 자동 생성 목차 그대로 사용
- ☑ 목차 커스텀 수정 (제목 변경)
- ☑ 차례 순서 재배열

---

### Step 5: 최종 확인 & PDF 생성
```
질문: "최종 설정을 확인하고 PDF를 생성할까요?"
타입: 확인 후 생성 또는 수정
```

**최종 검증 체크리스트:**
```
✓ 챕터 파일: [3개 선택됨]
✓ 레이아웃: 기본 (Basic)
✓ 제목: "AI 시대의 커리어 변화"
✓ 저자: "도시가스 안전기획자, 화상영어교사 외"
✓ 목차: 3개 챕터 확인됨
✓ 출력 폴더: 2.4_전자책_발간/
```

**선택지:**
- ✅ 확인, PDF 생성 시작!
- 🔄 설정 수정하기
  - 레이아웃 변경
  - 표지 정보 수정
  - 목차 재검토
  - 챕터 재선택

## 📄 PDF 생성 내용 구성

생성된 PDF의 구조:

### 1️⃣ 표지 (Cover Page)
- 제목
- 부제목 (있으면)
- 저자명
- 표지 이미지 (있으면)

### 2️⃣ 속표지 (Title Page)
- 제목 재표시
- 발행 정보
  - 발간일: [생성 날짜]
  - 저자: [입력 정보]
  - 버전: v1.0

### 3️⃣ 목차 (Table of Contents)
- 자동 생성 + 사용자 검증됨 목차
- 페이지 번호 자동 기재

### 4️⃣ 본문 (Chapters)
- 각 챕터 간 페이지 브레이크 삽입
- 챕터 헤더 (Chapter N. 제목)
- 마크다운 서식 → PDF 변환

### 5️⃣ 부록 (Appendix) - 선택
- 인터뷰이 소개 (Step 1 선택 파일 기반)
- 참고 자료 링크

### 6️⃣ 뒷표지 (Back Cover)
- 짧은 설명
- e-book 발행 정보
- 저자 연락처 (선택)

## ✅ 에이전트 품질 검증 체크리스트

PDF 생성 후 검증 항목:

- [ ] **표지**: 모든 정보가 정확히 표시되는가?
- [ ] **목차**: 페이지 번호가 올바르게 링크되는가?
- [ ] **본문**: 마크다운 서식이 올바르게 변환되었는가?
- [ ] **폰트**: 선택한 레이아웃의 폰트가 적용되었는가?
- [ ] **마진**: 여백이 적절히 설정되었는가?
- [ ] **페이지 브레이크**: 챕터 간 구분이 명확한가?
- [ ] **이미지**: 표지 이미지가 올바르게 삽입되었는가? (있으면)
- [ ] **파일명**: 규칙에 맞게 저장되었는가?
