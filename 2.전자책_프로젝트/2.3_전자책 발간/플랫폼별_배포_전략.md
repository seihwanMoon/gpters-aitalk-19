## 2. 주요 배포 플랫폼별 설정 가이드

### 플랫폼 1: Amazon KDP (Kindle Direct Publishing)

**플랫폼 특징**:
- 전 세계 최대 규모의 전자책 시장
- 한국 독자층에 매우 강함
- 가장 높은 로열티 제공

**설정 단계**:

#### 1단계: KDP 계정 생성
1. kdp.amazon.com 방문
2. Amazon 계정으로 로그인 (또는 신규 생성)
3. 저자 프로필 설정

#### 2단계: 책 정보 입력

| 항목 | 입력값 |
|------|--------|
| **책 제목** | 화상영어교사가 말하는 AI 시대의 성찰 |
| **부제** | 27분 인터뷰로 풀어낸 AI 활용의 현실과 과제 |
| **저자** | [저자명] 또는 인터뷰 참여자명 |
| **출판사** | 독립 출판 (또는 표시 안 함) |
| **출판 날짜** | 2025-10-23 |
| **언어** | 한국어 |
| **카테고리** | 과학&기술 > 인공지능 |
| **부 카테고리** | 비즈니스&금융 > 기술 비즈니스 |

#### 3단계: 책 설명 (Description)

**Amazon KDP용 책 설명** (약 200-300단어):
```
AI 도구를 매일 사용하는 현장 전문가의 솔직한 성찰

현대 직장인들이 가장 궁금해하는 AI에 대해,
실제로 매일 AI를 활용하는 교사는 어떻게 생각할까요?

이 책은 화상영어 교사와의 27분 인터뷰를 통해
AI의 생산성, 윤리, 그리고 인간관계에 대한
깊이 있는 성찰을 담아냅니다.

주요 내용:
- AI 도구 활용의 현실적 경험 (ChatGPT, 미리캔버스 AI, 구글 AI)
- 생산성과 정체성의 상충에서 오는 심리적 딜레마
- 사고력 저하에 대한 근본적 우려
- 교육 현장에서 마주한 실제 사례와 에피소드
- AI 시대의 윤리와 가치에 대한 통찰

이 책은 AI 기술에 대한 추상적 논의를 넘어,
실제로 우리가 어떻게 살아가는지를 보여줍니다.

기술의 편리함을 누리되, 인간적 가치를 잃지 않기 위해
우리가 어떻게 해야 할지 함께 고민해봅시다.
```

#### 4단계: 키워드 설정

**검색 키워드** (최대 7개):
1. AI 활용
2. ChatGPT 사용법
3. 인공지능 윤리
4. 기술 트렌드
5. 디지털 리터러시
6. 직장인 자기계발
7. 4차산업혁명

#### 5단계: 가격 설정

**권장 가격**:
- 한국: 9,900원 (원본 길이 약 50쪽)
- 국제 판매가: $7.99 USD

**가격 책정 전략**:
- 유사 한국 에세이 전자책 기준: 7,000-12,000원
- 인터뷰 기반 가 론픽션: 중상 가격대 추천

#### 6단계: 파일 형식 준비

**필요한 파일**:
- **콘텐츠 파일**:
  - 마크다운 → DOCX → KDP 업로드 형식으로 변환
  - 또는 HTML 형식 제출

- **표지 이미지**:
  - 크기: 1600x2560 픽셀 (최소)
  - 형식: JPG 또는 PNG
  - 해상도: 300 DPI 권장
  - 텍스트 크기: 충분히 커야 함 (작은 화면에서도 읽히도록)

#### 7단계: ISBN 선택

**옵션**:
- **무료 KDP ISBN** (추천): Amazon에서 제공하는 KDP ISBN 사용
  - 장점: 무료, 간편, KDP 내에서만 사용 가능
  - 단점: 다른 플랫폼에서 재판매 불가

- **구매 ISBN**: 직접 구입
  - 비용: 1개 약 25,000원 (한국)
  - 장점: 모든 플랫폼에서 사용 가능
  - 단점: 비용 발생

**권장**: 와이드 배포 계획이면 구매 ISBN,
KDP 독점이면 KDP ISBN 사용

#### 8단계: 로열티 프로그램 선택

**옵션 A: KDP Select (독점 배포)**
- 장점:
  - 35% 또는 70% 로열티 선택 가능
  - Kindle Unlimited 프로그램 참여
  - 더 높은 로열티율
- 단점:
  - 90일 독점 계약
  - 다른 플랫폼에 동시 배포 불가

**옵션 B: KDP Standard (비독점)**
- 장점:
  - 다른 플랫폼에 동시 배포 가능
  - 35% 로열티
  - 자유로운 배포 전략
- 단점:
  - 70% 로열티 옵션 없음
  - KU 프로그램 참여 불가

**권장**: 와이드 배포를 위해 KDP Standard 선택

#### 9단계: 출판 및 배포

1. 모든 정보 입력 완료
2. "검토를 위해 제출" 클릭
3. Amazon 자동 검토 (24-48시간)
4. 승인 후 즉시 판매 시작

**배포 소요 시간**: 24-48시간

## 3. 파일 형식별 준비 가이드

### EPUB3 형식 (Apple Books, Google Play Books 권장)

**EPUB3란?**:
- 가장 최신의 전자책 표준 형식
- 다양한 기기와 화면 크기에 자동 적응
- 모든 주요 플랫폼에서 지원

**준비 방법**:

#### 옵션 1: 온라인 변환 도구 사용 (가장 간단)
1. pandoc.org 또는 CloudConvert.com 방문
2. 마크다운 파일 또는 DOCX 업로드
3. EPUB3로 변환
4. 다운로드

#### 옵션 2: Calibre 사용 (권장, 무료)
1. calibre-ebook.com에서 다운로드
2. Calibre 설치
3. 프로그램 열기
4. "책 추가" > DOCX 파일 선택
5. 우클릭 > "전자책 변환"
6. 출력 형식: EPUB
7. 메타데이터 편집 (제목, 저자 등)
8. "확인" 클릭

#### 옵션 3: Sigil 사용 (고급 사용자)
1. sigil-ebook.com에서 다운로드
2. Sigil 설치
3. 파일 > 새로 만들기
4. HTML 콘텐츠 편집
5. 저장 (EPUB 형식)

**EPUB3 검증**:
- W3C EPUB Validator (validator.w3.org/epub/)
- 업로드 후 검증하여 오류 확인

---

### MOBI/AZW3 형식 (Amazon Kindle)

**MOBI/AZW3란?**:
- Amazon Kindle 전용 형식
- MOBI는 구형, AZW3는 신형 표준
- 최신 Kindle 기기는 AZW3 권장

**준비 방법**:

#### 옵션: Amazon Kindle Previewer 사용
1. amazon.com에서 Kindle Previewer 다운로드
2. DOCX 또는 HTML 파일 준비
3. Kindle Previewer 열기
4. 파일 > 열기 > DOCX 선택
5. 미리보기 확인
6. KDP에 직접 업로드 (자동 변환됨)

**권장**: KDP 사이트에서 자동 변환 기능 사용 (수동 변환 불필요)

---

### PDF 형식 (배포보다는 보관용)

**주의사항**:
- 대부분의 플랫폼에서는 PDF 지원하지 않음
- 반응형 텍스트 부족 (작은 화면에서 읽기 어려움)
- 고정 레이아웃용으로만 권장

**PDF 준비 방법**:
1. Microsoft Word에서 마크다운 파일을 DOCX로 저장
2. Word > 다른 이름으로 저장 > PDF 형식 선택
3. 또는 구글 독스 > 다운로드 > PDF

## 4. 표지 디자인 가이드

### 표지 규격

| 항목 | 규격 |
|------|------|
| **픽셀 크기** | 1600 x 2560 픽셀 (최소) |
| **종횡비** | 1:1.6 (가로:세로) |
| **해상도** | 300 DPI (인쇄 품질) |
| **파일 형식** | JPG 또는 PNG |
| **최대 파일 크기** | 10MB |

### 표지 요소 체크리스트

필수 요소:
- [ ] 명확한 책 제목 (작은 화면에서도 읽힐 크기)
- [ ] 부제 (선택적이지만 권장)
- [ ] 저자명
- [ ] 배경 이미지 또는 색상 (AI 관련 시각적 요소)

디자인 권장사항:
- [ ] 전문성 있는 디자인 (에세이/학술서적 톤)
- [ ] 고대비 색상 사용 (접근성 고려)
- [ ] 타이포그래피: 명확하고 읽기 쉬운 폰트
- [ ] AI 시대의 현대적 감각 반영

### 표지 디자인 팁

**추천 디자인 방향**:
1. **현대적 미니멀리즘**: 깔끔한 라인과 타이포그래피
2. **기술적 감성**: AI, 기술, 미래를 암시하는 그래픽 요소
3. **전문성**: 에세이/학술서적으로 신뢰감 있는 톤

**무료 디자인 도구**:
- Canva Pro (canva.com): 전자책 표지 템플릿 제공
- GIMP (무료 포토샵 대체): 상세한 디자인 가능
- Pixlr (pixlr.com): 온라인 편집 도구

**유료 디자인 서비스**:

## 8. 문제 해결 가이드

### 배포 거부 시

**일반적 거부 이유**:
1. **메타데이터 오류**: 제목 중복, 부적절한 콘텐츠
   - 해결: 메타데이터 수정 후 재제출

2. **파일 형식 오류**: EPUB 구조 손상, 인코딩 문제
   - 해결: Calibre나 Sigil로 파일 재생성

3. **저작권 문제**: 원본 콘텐츠 확인 필요
   - 해결: 저작권 보유 확인 후 재제출

4. **콘텐츠 정책 위반**: 부적절한 내용
   - 해결: 플랫폼 가이드라인 재검토, 필요시 내용 수정

### 검색 최적화 실패 시

**원인 분석**:
1. 키워드 관련성 낮음
2. 카테고리 부적절
3. 책 설명 불충분
4. 리뷰 부족

**해결 방법**:
1. 키워드 재분석 (Google Keyword Planner 사용)
2. 카테고리 재조정
3. 책 설명 상세화
4. 리뷰 요청 강화
