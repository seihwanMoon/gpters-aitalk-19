## 인터뷰 질문 (핵심 요약)

| 질문                                             | 답변 내용                                                                                    |     |
| :--------------------------------------------- | :--------------------------------------------------------------------------------------- | --- |
| **현재 주로 사용하는 AI 도구와 사용 목적이 무엇인가요?**            | **ChatGPT, 미리캔버스 AI, 구글 AI**. **업무 효율화**(PPT 초안, 수강 후기 답변) 및 **정보 검색**(맛집, 드라이브 코스)에 사용. |     |
| **AI가 만들어낸 결과물(글, 이미지 등)을 본인의 ‘창작물’로 생각하시나요?** | **아니오**. AI가 만든 결과물은 나의 것이 아님. 진짜 창작의 핵심은 내 머릿속에서 나온 **'프롬프트(입력값)'**라고 생각.               |     |
| **AI 챗봇이 감정적 위로를 줄 수 있다고 생각하시나요?**             | **아니오**. AI에게는 **감정이 없다**고 생각함. 진정한 위로를 주기보다, 생각을 정리하는 **'낙서장'** 정도의 역할.                 |     |
| **AI를 사용하지 않아 뒤처지는 듯한 불안감을 느끼시나요?**            | **직접적 불안감은 아님**. 다만, AI를 잘 활용하지 못하는 사람에게는 최신 기술(AI폰 등)이 **매력적으로 다가오지 않음**.               |     |
| **AI 발전과 관련하여 가장 우려되는 점은 무엇인가요?**              | **사고 능력의 저하**. AI에 대한 의존이 높아져 사람들이 **'멍청해지는 느낌'**을 받고, 스스로 창안하는 능력이 줄어들 것을 우려.           |     |
| **만약 선택지가 주어진다면 AI가 없던 과거로 돌아가시겠습니까?**         | **안 돌아감**. 반복적인 업무를 줄여주는 등 **너무 편하기 때문**. 시간 단축 효과가 매우 큼.                                |     |


## 인사이트


### 1. 감정 교류의 명확한 한계

인터뷰이는 AI를 정서적 교류의 대상이 아닌, 
'생각 정리용 도구'로 명확히 선을 긋습니다. 

AI의 공감에는 감정이 부재하며, 
형식적인 답변은 진정한 위로를 줄 수 없다고 판단합니다. 
이는 AI가 인간의 복잡한 감정 영역을 대체할 수 없다는 인식을 보여줍니다.


### 2. 생산성과 정체성의 상충 관계

AI는 반복 업무의 효율을 극대화하여 생산성을 높이지만, 
동시에 결과물에 대한 개인의 정체성 혼란을 야기합니다. 

AI의 도움으로 얻은 성과가 온전히 자신의 것으로 인정받기 어렵다는 
'양심의 가책'은, 기술 활용의 이면에 존재하는 심리적 딜레마를 드러냅니다.


### 3. 사고력 저하에 대한 근본적 우려

기술적 도태에 대한 불안감보다, 
AI 의존으로 인한 인간의 '사고력 저하'를 더 큰 위협으로 간주합니다. 
AI가 정답을 쉽게 제공함으로써, 
스스로 탐구하고 발전하려는 동기가 약화될 수 있다는 점을 가장 경계합니다.


### 4. 기술의 보편적 가치와 가능성

개인적 우려와는 별개로, 
AI가 세대와 기술 숙련도를 넘어 
모두에게 실질적인 혜택을 줄 수 있다는 점을 명확히 인지합니다. 

특히 언어 장벽 해소와 같은 보편적인 문제 해결에서 AI의 긍정적 가능성을 발견합니다.


## 에피소드


### 1. 칭찬이 부른 양심의 가책

수십 개의 수강 후기 답변을 AI의 도움으로 순식간에 작성한 후, 
상사로부터 "글을 참 잘 쓴다"는 칭찬을 들었습니다. 

인터뷰이는 이때 기쁨보다 "내가 한 것이 아닌데"라는 
생각에 양심의 가책을 느꼈다고 말합니다. 
이 경험은 AI 시대의 성과와 기여에 대한 깊은 고민을 안겨주었습니다.


### 2. 부모님의 일본 의약품 설명서

부모님께서 일본 여행에서 사 온 의약품 설명서를 
이해하지 못해 곤란을 겪고 있었습니다. 

이때 스마트폰의 '사진 번역' 기능을 이용해 즉시 내용을 파악할 수 있었습니다. 

이 일화는 기술에 익숙지 않은 세대조차 
AI를 통해 정보 격차와 언어의 장벽을 쉽게 넘을 수 있음을 
보여주는 대표적인 사례입니다.


### 3. "GPT가 있는데, 왜 외국어 공부를 하죠?"

학습 매니저로 일하며 만난 한 학생은 
"GPT와 대화하면 되는데, 굳이 외국인과 대화할 필요가 있나요?"라고 반문했습니다. 

이 질문은 AI가 편리함을 넘어, 
실제 경험을 통해 배우려는 학습 동기 자체를 약화시킬 수 있다는 
현실적인 우려를 느끼게 했습니다.


### 4. 나만의 비밀 낙서장

인터뷰이는 타인에게 말하기 힘든 고민을 AI에게 털어놓곤 합니다. 
하지만 AI의 답변에서 어떤 감정적 위안도 얻지 못하며, 
"과연 AI가 감정이 있을까?"라는 회의감을 느낍니다. 

결국 그녀에게 AI는 정서적 교류 상대가 아닌, 
자신의 생각을 배설하고 정리하는 '비밀 낙서장'으로만 기능하고 있습니다.
