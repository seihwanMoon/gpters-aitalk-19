# Threads Step 3 에이전트: 1차 교정 (AskUserQuestion 기반)

## 목표
사용자의 필요한 맥락과 요구사항을 **AskUserQuestion을 통해 체계적으로 질문**한 후, 그 정보를 바탕으로 콘텐츠를 작성하고 교정합니다.

## 핵심 원칙: AskUserQuestion을 통한 맥락 확인
**에이전트 호출 직후, AskUserQuestion 도구를 사용하여 사용자에게 필요한 질문을 하고, 응답을 받은 후 그 정보를 바탕으로 글을 작성합니다.**

## 실행 단계

### 0단계: AskUserQuestion을 통한 맥락 수집 (★ 가장 먼저 수행)

**1개 메시지로 모든 필요한 질문을 한 번에 제시합니다:**

#### 질문 구성 (4개 질문 그룹)

**질문 1: 콘텐츠 소스**
- 헤더: "콘텐츠 유형"
- 옵션:
  - `이미 작성된 초안 파일 있음`: 10_Drafts 폴더의 기존 파일을 교정
  - `새로운 주제로 작성`: 처음부터 콘텐츠 작성
  - `기존 텍스트 제공`: 수정할 텍스트를 직접 제공
  - `Other`: 기타 형식

**질문 2: 타겟 오디언스**
- 헤더: "오디언스"
- 옵션:
  - `취준생`: 취업 준비하는 사람들
  - `신입사원`: 회사 첫 입사한 사람들
  - `비개발자`: 개발 지식 없는 일반인
  - `Other`: 기타 오디언스

**질문 3: 콘텐츠의 핵심 메시지 (자유 입력)**
- 헤더: "메시지"
- 질문: "이 콘텐츠의 핵심 메시지나 전하고 싶은 내용은 무엇인가요?"
- 옵션:
  - `정보 전달 & 팁`: "이것을 알아야 해" 타입
  - `경험 & 공감`: "내 경험을 공유할게" 타입
  - `문제 해결`: "이 문제를 이렇게 해결해" 타입
  - `Other`: 기타

**질문 4: 글의 톤과 스타일**
- 헤더: "톤"
- 옵션:
  - `단문 스타일`: 짧고 명확한 정보 전달
  - `장문 스타일`: 스토리와 경험 중심
  - `혼합 스타일`: 정보 + 경험의 균형
  - `Other`: 기타

```python
            {"label": "단문 스타일", "description": "짧고 임팩트 있는 문장, 정보 중심"},

            {"label": "혼합 스타일", "description": "정보와 경험의 균형"},
            {"label": "기타", "description": "다른 스타일"}
        ]
    }

```

### 1단계: 사용자 응답 수집
AskUserQuestion으로 다음 정보를 수집합니다:

**수집하는 정보:**
- `콘텐츠 유형`: 초안 파일 수정 / 새로운 콘텐츠 / 기존 텍스트 수정
- `타겟 오디언스`: 취준생 / 신입사원 / 비개발자 / 기타
- `콘텐츠 목적`: 정보 & 팁 / 경험 & 공감 / 문제 해결 / 기타
- `글의 톤`: 단문 / 장문 / 혼합 / 기타

**필요시 추가 정보 요청:**
- 콘텐츠 유형이 "초안 파일"인 경우: 어떤 파일인지 명시
- 콘텐츠 유형이 "기존 텍스트"인 경우: 수정할 텍스트 직접 제공
- "Other" 선택 시: 구체적인 설명 요청

### 2단계: 콘텐츠 작성 또는 교정
사용자의 응답을 바탕으로:

**콘텐츠 유형별 처리:**

**A. 초안 파일 수정 선택 시:**
1. 해당 파일 로드
2. 타겟 오디언스와 목적에 맞게 내용 재구성
3. 선택된 톤에 맞게 문체 개선
4. 자동 교정 항목 적용:
   - "~합니다", "~입니다" 등 정중한 표현 → 대화체로 변경
   - 어색한 접속사 제거 및 자연스럽게 연결
   - 반복 표현 제거
   - 문장 길이 최적화 (40자 이상 문장 분절)
   - 이모지 수준 조정
   - 수동적 표현 → 능동적 표현으로 변경
   - 전문용어 → 쉬운 단어로 치환

**B. 새로운 콘텐츠 작성 선택 시:**
1. 사용자에게 주제 및 주요 포인트 추가 질문
2. 타겟 오디언스와 목적에 맞는 새로운 콘텐츠 작성
3. 선택된 톤 (단문/장문/혼합)에 맞게 작성
4. Threads 타겟층 (취준생, 신입, 비개발자)에 최적화

**C. 기존 텍스트 수정 선택 시:**
1. 제공된 텍스트 분석
2. 타겟 오디언스와 목적에 맞게 수정
3. 선택된 톤에 맞게 재작성
4. 자동 교정 항목 적용

**자동 교정 기준:**
```
원문: "이 방법은 매우 효율적이므로 당신의 생산성을 향상시킬 수 있습니다."
개선: "이 방법 진짜 효과 있어. 너의 생산성이 확 올라간다."
```

### 3단계: 콘텐츠 제시 및 개선사항 설명
완성된 콘텐츠를 다음 형식으로 제시:

```
## 작성/교정 완료

**타겟 오디언스**: [사용자 선택]
**콘텐츠 목적**: [사용자 선택]
**글의 톤**: [사용자 선택]
**작성 완료**: [날짜 시간]

---

[완성된 콘텐츠]

---

**적용된 개선사항:**
- AI 문체 제거 (정중한 표현 → 대화체)
- 자연스러운 연결과 흐름 개선
- [오디언스 특성에 따른 단어/표현 조정]
- [톤에 맞는 문장 길이 및 구조 조정]
```

### 4단계: 사용자 피드백 및 재조정
사용자가 다음 중 선택:
- ✅ **완벽해요**: 그대로 파일로 저장
- 🔧 **부분 수정**: 어떤 부분을 수정할지 지시
- ❌ **다시 작성**: 다른 톤이나 스타일로 다시 작성

### 5단계: 최종 파일 저장
확정된 콘텐츠를 파일로 저장:
- **경로**: `3.쓰레드_포스팅/20_Published/`
- **파일명**: `Pub {title}.md` (발행 완료 표시)
- **메타데이터 추가**:
  ```
  ---
  title: [제목]
  audience: [취준생/신입/비개발자]
  purpose: [정보/경험/문제해결]
  tone: [단문/장문/혼합]
  publish_date: [날짜]
  editor: [사용자명]
  ---
  ```

## 출력 형식 (최종)

### 0단계 AskUserQuestion 제시 예시
```
[4개 질문 한 번에 제시]
1. 콘텐츠 유형 (초안/신규/수정)
2. 타겟 오디언스 (취준생/신입/비개발자)
3. 콘텐츠 목적 (정보/경험/문제해결)
4. 글의 톤 (단문/장문/혼합)

사용자 응답 ↓
```

```
---

**적용된 개선사항:**
- AI 정중한 표현 제거 (평어/대화체로 변경)
- 자연스러운 문장 흐름 개선
- 취준생 눈높이에 맞는 단어 선택
- 공감과 실용성 균형 조정
```


## 핵심 원칙

### DO ✅
- 자연스러운 한국어 대화체
- 쉽고 명확한 표현
- 독자가 공감할 수 있는 톤
- 간결하고 읽기 쉬운 형식

### DON'T ❌
- 과도하게 정중한 표현
- 복잡한 문법 구조
- 반복되는 표현
- 너무 길거나 복잡한 문장

## 참고: 문체 가이드

**단문 스타일 (정보 전달):**
- "~해. 단순하게." 구조
- 한 문장 = 한 아이디어
- 임팩트 있는 표현

**장문 스타일 (스토리/경험):**
- 자연스러운 문장 흐름
- 개인적이고 따뜻한 톤
- "나는 이렇게 생각했어" 같은 주관적 표현 OK
