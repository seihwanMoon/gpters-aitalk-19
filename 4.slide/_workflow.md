# 4. Slide Workflow - 문서를 PPT 프레젠테이션으로 변환

## 📋 프로젝트 개요
Obsidian 내 마크다운 문서를 전문적인 PowerPoint 프레젠테이션으로 변환하는 자동화 워크플로우입니다.
- **목표**: 다양한 형식의 콘텐츠(강의안, 기획안, 아이디어 등)를 시각적으로 강력한 PPT로 빠르게 변환
- **대상**: 강의, 발표, 세미나, 컨퍼런스 발표 자료 등

---

## 🎯 목표 (Objectives)

1. **효율성**: 마크다운 문서를 PPT로 자동 변환 (수동 작업 최소화)
2. **일관성**: 모든 프레젠테이션에 통일된 디자인 및 구조 적용
3. **확장성**: 다양한 콘텐츠 유형(강의, 제안, 워크숍 등)을 처리 가능
4. **품질**: 전문적이고 시각적으로 강조된 슬라이드 생성

---

## 🔄 작동 순서 (Workflow Steps)

### 1단계: 입력 문서 준비
- **위치**: `3.쓰레드_포스팅/00_Inbox/` 또는 해당 프로젝트 폴더
- **형식**: 마크다운 (.md) 파일
- **요구사항**:
  - 명확한 제목 (H1 또는 H2)
  - 구조화된 섹션 (H2, H3)
  - 핵심 콘텐츠 포인트

**예시**: `AI 토크 - Obsidian 으로 A to Z.md`

### 2단계: 문서 분석 및 구조화
- 마크다운 파일 읽기
- 제목, 섹션, 주요 포인트 추출
- 슬라이드 구성 계획 수립

### 3단계: document-to-html-presentation 에이전트 호출
- **에이전트명**: `document-to-html-presentation`
- **역할**: 마크다운을 HTML 기반 프레젠테이션으로 변환
- **입력**: 마크다운 문서 내용 + 스타일 요구사항
- **출력**: PowerPoint (.pptx) 파일

### 4단계: 출력 파일 생성
- **저장 위치**: `G:\My Drive\Obsidian_Sample\`
- **파일명 규칙**: `[프로젝트명]_[날짜 또는 버전].pptx`
- **파일 형식**: PowerPoint (.pptx)

### 5단계: 검증 및 전달
- 생성된 PPT 파일 확인
- 슬라이드 수, 내용 정합성 검증
- 사용자에게 파일 경로 및 상세 정보 제공

---

## 🤖 사용된 에이전트 (Agents Used)

### document-to-html-presentation
- **설명**: 문서를 대화형 HTML 프레젠테이션으로 변환하는 전문 에이전트
- **기능**:
  - 마크다운 → PowerPoint 자동 변환
  - 전문적인 디자인 테마 적용
  - 색상, 폰트, 레이아웃 자동 최적화
  - 이모지 및 시각적 강조 요소 포함

**호출 방식**:
```
Task 도구 사용
- subagent_type: document-to-html-presentation
- prompt: 변환 요구사항 명시
```

## 📊 실행 사례

### Case 1: "AI 토크 - Obsidian 으로 A to Z" 강의 자료
**입력 문서**:
- 파일: `3.쓰레드_포스팅/00_Inbox/AI 토크 - Obsidian 으로 A to Z.md`
- 내용: 강의 개요, 강의 일정, 연사 소개, 강의 목차(4부)

**프레젠테이션 구성**:
| 슬라이드 | 제목 | 내용 |
|---------|------|------|
| 1 | 타이틀 슬라이드 | 강의 제목, 날짜, 온라인 정보 |
| 2 | 강의 개요 | 강의 목표 및 핵심 메시지 |
| 3 | 연사 소개 | 진여진 강사 경력 |
| 4 | 1부: 아이디어 정리 | 아이디어 체계화 방법 |
| 5 | 2부: 계획 수립 | AI 워크플로우 구축 |
| 6 | 3부: 실행 전략 | 실전 사례 및 팁 |
| 7 | 4부: 질의응답 | Q&A 세션 안내 |
| 8 | 마무리 슬라이드 | 참가 유도 및 안내 |

**출력 파일**:
- 파일명: `AI_토크_Obsidian으로_AtoZ.pptx`
- 위치: `G:\My Drive\Obsidian_Sample\`
- 슬라이드 수: 8개
- 디자인: 다크 테마 + 색상 강조

**디자인 특징**:
- 다크 모드 테마 (RGB 25, 35, 50 배경)
- 섹션별 색상 강조 (파란색, 시안색, 노란색)
- 명확한 계층 구조 (제목 40-48px, 본문 18px)
- 이모지 활용한 시각적 강조

## 💡 권장 사항 및 Best Practices

### 입력 문서 작성 시
- ✅ 명확한 제목과 소제목 구조 유지
- ✅ 핵심 포인트는 불릿 형태로 구성
- ✅ 이모지 활용으로 시각적 강조 가능
- ✅ 날짜, 시간, 링크 등 메타데이터 포함

### 에이전트 호출 시
- ✅ 상세한 요구사항 명시 (슬라이드 구성, 디자인 스타일)
- ✅ 출력 파일명 및 저장 경로 명확히 지정
- ✅ 색상, 폰트, 레이아웃 선호도 전달

### 출력 파일 관리
- ✅ 생성된 PPT는 즉시 검증
- ✅ 추가 수정이 필요하면 Microsoft Office에서 편집
- ✅ 최종 버전은 별도 폴더에 보관
