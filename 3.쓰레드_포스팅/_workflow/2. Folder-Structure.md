## Prompt

```md
[[1. Requirement]] 문서를 바탕으로 올바른 Folder 구조를 갖추어라
최소 프로세스를 위한 작업 공간을 목표한다.
이해한 최우선 가치를 되묻고 사용자에게 허락을 받으면 
Folder 구조 갖추기 작업을 진행하라
```


## 결과

*   `00_Inbox/`
    *   **역할:** 외부 자료(아티클, 유튜브, 좋은 스레드 등)를 클리핑하여 모아두는, 아직 가공되지 않은 아이디어의 보관소입니다.
*   `10_Drafts/`
    *   **역할:** `00_Inbox`의 자료를 바탕으로 Gemini-CLI를 통해 생성된 스레드 초안들을 저장하는 공간입니다. 수정과 개선이 이루어지는 단계입니다.
*   `20_Published/`
    *   **역할:** 최종적으로 발행이 완료된 스레드를 보관하는 아카이브입니다. 나중에 전자책이나 강의 자료로 재활용될 자산이 됩니다.
