## Prompt

```md
나는 Thread 팔로워 500 명이상 되고 싶어
이 목표를 이루기 위해, 타겟층, 프로세스, 컨텐츠와 프로젝트를 논의 후 정의한다
초기 목표 : 팔로워 500 명 이후, 패스트캠퍼스 강의, 전자책 발간을 목표한다

```

## 그래서 나온 프로젝트 초안

- 목표
	- Thread 업로드를 위해 자료를 저장, 글쓰기, 발간까지 작업하는 프로젝트이다.
	- 팔로워 500명, 시리즈 발간물을 통해 
		- 전자책 발간
		- 온라인 강의를 목표한다
	- 핵심 컨텐츠
		- Obsidian
		- 바이브 코딩
		- 프로젝트 외주
		- 개발자
- 타겟 
	- 2030 취준생
	- 바이브 코딩 초보자, 입문자
	- 프롬프트를 잘 작성하고 싶은 사람
	- 프리랜서에 관심이 있는 사람
- 키워드
	- 개발자, dev
	- 바이브 코딩
	- Obsidian
	- Obsidian 자동화
	- 사이드 프로젝트
	- 포트폴리오
	- 외주

### 세부 논의 : 최소 단위
- 자료 저장
	- Obsidian Clipper 를 이용해 아티클, Youtube 영상을 클리핑한다 
	- Thread 의 주요한 내용은 사용자가 직접 클리핑을 진행한다
	- 개인 회고
- 글쓰기 
	- 자료와 사용자가 원하는 글쓰기를 Gemini-CLI 를 통해 글쓰기 작업을 진행한다 
- 발간
	- `절대 API 연결을 통해 작업하지 않는다`
	- 연동의 사용되는 시간이 오래걸릴 것으로 우려,
	- 컨텐츠 업로드와 팔로워가 좋아하는 내용이 무엇인지 집중하는 것을 최우선 가치로 진행한다
