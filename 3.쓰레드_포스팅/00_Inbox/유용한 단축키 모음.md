# 브라우저

- Ctrl + T : 새 탭

- 왼쪽 탭으로 이동 : Ctrl + 3
- 이전 페이지로 이동 : Alt + `<-`
- 페이지 닫기 : Ctrl + W

# Window 

## Ctrl 

- 맨 윗줄로 이동 : Ctrl + 숫자패드 7
- 맨 아랫줄로 이동 : Ctrl+ 숫자패드 1
- 오른쪽 탭으로 이동 : Ctrl + 9
- 왼쪽 탭으로 이동 : Ctrl + 3


## Win

- 스크린 캡쳐 : Win + Shift + S
- 화면 확대 : win + +/-
- 화면 이동 : Win + 방향키
- 가상 데스크탑 생성 : Win + Ctrl + D
- 가상 데크스탑 이동 : Win + Ctrl + 방향키
